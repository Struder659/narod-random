# Случайный Народ

Интерфейс: https://struder659.github.io/narod-random/

GitHub Pages раздаёт HTML, CSS и JavaScript. Поиск и создание превью выполняются по запросу в Vercel Functions с Fluid Compute (`fluid: true`). Базы данных, готового каталога сайтов и фоновой сборки подборок нет.

## Поиск

Каждое нажатие отправляет POST /api/random. Сервер читает случайные блоки публичного индекса Common Crawl, выбирает домены narod.ru и проверяет их доступность сейчас. Ошибки HTTP, заглушки удалённых сайтов и перенаправления на посторонние домены отбрасываются. Индекс — источник адресов; наличие адреса в индексе само по себе не считается проверкой доступности.

В оперативной памяти экземпляра функции остаются ограниченный пул кандидатов и метаданные индекса. Они исчезают при остановке экземпляра. Просмотренные домены сохраняются только в браузере пользователя (до 10 000) и передаются как исключения для поиска. Полной равномерности по всему narod.ru или вечной доступности найденной страницы нет.

URL появляется сразу после проверки. Отдельный POST /api/preview создаёт JPEG 320×240 через Chromium. Сайт можно открыть, пока картинка готовится. Скрипты чужих сайтов и ресурсы вне narod.ru отключены. При ошибке превью ссылка остаётся рабочей независимо от картинки. Недавние превью могут храниться только в памяти функции, до 20 снимков на 10 минут.

## Развёртывание

Node.js 24. `vercel.json` включает Fluid Compute и устанавливает лимиты выполнения. Chromium упакован в функцию через @sparticuz/chromium; браузер пользователя не используется. Все запросы ограничены по времени, CORS разрешает интерфейс https://struder659.github.io. Для локальной разработки также разрешён localhost:5175.

1. Развернуть API на Vercel Hobby из этого проекта (CLI или GitHub integration). Build command: node scripts/build-api.mjs; output: public; framework: Other.
2. Указать полученный постоянный HTTPS origin в site/config.js (API_BASE).
3. Выполнить npm test и npm run build.
4. Публиковать dist-pages через workflow Publish Narod. Расписания обновления каталога нет: workflow только публикует интерфейс после изменения кода.

Не включать Vercel Authentication для production API: посетителям GitHub Pages нужен публичный доступ. Секреты и токены Vercel в интерфейс не добавляются.

## Локальная проверка

```
npm ci
npm test
npm run dev:api
```

Во втором терминале: `npm run preview`. Интерфейс http://127.0.0.1:5175 использует API http://127.0.0.1:5176. Для локальных превью нужен установленный Google Chrome.

Бесплатный Hobby ограничен квотами Vercel. Время первого запуска функции и Chromium, доступность индекса и скорость старых сайтов влияют на задержки; Fluid Compute не гарантирует мгновенную выдачу.
