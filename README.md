# Случайный Народ

https://struder659.github.io/narod-random/

Статический сайт на GitHub Pages. Без базы данных, внешнего сервера и платного сервиса снимков.

## Как работает

GitHub Actions при публикации и раз в 6 часов выбирает случайные блоки публичного индекса Common Crawl, находит живые HTML-сайты на narod.ru и создаёт JPEG-превью 320×240 через Chrome. Цель сборки — 60 сайтов, допустимый минимум — 12. Проверка и скриншоты происходят при сборке, а не при нажатии посетителя. Доступность сайта после проверки не гарантируется; время проверки показано под результатом.

Сборка публикует JSON-файл и картинки вместе с HTML/CSS/JS. Данные не коммитятся в Git. При ошибке или слишком малом числе сайтов публикация не выполняется: предыдущая версия остаётся доступна. Расписание GitHub может задерживаться и отключается после длительного отсутствия активности в публичном репозитории; обновление можно запустить вручную через Actions → Publish Narod → Run workflow.

Кнопка выбирает сайты в случайном порядке через Web Crypto. До исчерпания подборки повторов нет, затем порядок снова перемешивается. Первая страница следующего круга не повторяет предыдущую. Это выбор среди сайтов текущей сборки, а не равномерная выборка всего narod.ru.

## Разработка

Нужны Node.js 24 и Google Chrome. На GitHub используется Chrome, установленный в Ubuntu runner.

```
npm ci
npm test
npm run build
npm run preview
```

Локальный просмотр: http://127.0.0.1:5175. Для короткой пробной сборки задайте BUILD_TARGET=8 и BUILD_MINIMUM=4; обычная сборка ограничена семью минутами.

## Ограничения снимков

Скрипты сайтов не выполняются, внешняя реклама и ресурсы вне поддоменов narod.ru блокируются. Поэтому превью может отличаться от страницы при открытии. Проверяются адреса и публичные IP, браузер использует отдельные временные контексты. Зависшие загрузки ограничены по времени.

Оформление использует предоставленные пользователем исторические изображения narod.ru.
